# Vaulta Toolbox

Official release channel for **Vaulta Toolbox** — the Windows companion app for installing, updating, and managing [Vaulta Desktop](https://usevaulta.site).

Vaulta Toolbox ships as a system-tray application for everyday use and a terminal installer for scripted setups.

## Download

Latest installers: [Releases](https://github.com/usevaulta/toolbox-releases/releases)

Or install via PowerShell:

```powershell
irm https://usevaulta.site/install.ps1 | iex
```

This repository hosts release binaries only.
